# Quiz HTML 🎯

Esse foi meu primeiro projeto utilizando HTML, desenvolvido como parte do meu aprendizado inicial em desenvolvimento web.

## 📚 Sobre o projeto
Este projeto representa meu primeiro contato prático com desenvolvimento web usando HTML.

A proposta foi criar uma página de quiz interativo para praticar conceitos fundamentais de estruturação de páginas, organização de arquivos e estilização visual.

## 🚀 Tecnologias utilizadas
- HTML5

## 🎯 Objetivos de aprendizado
Durante o desenvolvimento deste projeto, pratiquei:

- Estrutura básica de uma página HTML
- Uso de tags semânticas
- Organização de arquivos e diretórios
- Inserção de imagens e recursos visuais
- Criação de elementos interativos
- Boas práticas iniciais de desenvolvimento web


Este projeto foi importante para consolidar meus primeiros conhecimentos em desenvolvimento web, permitindo compreender melhor como páginas web são estruturadas e estilizadas.

Melhorias futuras para o projeto:

Adicionar JavaScript para maior interatividade
Implementar sistema de pontuação
Melhorar a responsividade
Refinar a interface visual
Organizar melhor o código
